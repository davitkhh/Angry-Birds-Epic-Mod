Combatant Forge for Linux

Install:    ./install.sh
Run:        open Combatant Forge from your app menu
Uninstall:  ~/.local/share/CombatantForge/uninstall.sh

The first time it opens, choose the game project folder (the one that contains Assets).
To change it later: combatant-forge --project /path/to/the/game

Needs Python 3 and Pillow (sudo apt install python3 python3-pil).
For its own window instead of a browser tab: sudo apt install python3-gi gir1.2-webkit2-4.1
Your combatants are saved in the game project, under Tools/CombatantForge/projects.
